# Очистка Android-магнитолы по ADB

Скрипт подключается к магнитоле по сети (по умолчанию `192.168.2.150:5555`)
и удаляет мусор. Root не нужен.

## Что удаляется в режиме `clean`

- кэш всех приложений во внутренней памяти (`pm trim-caches`);
- `Android/data/*/cache` — внешний кэш приложений;
- `LOST.DIR` — обрывки файлов после сбоев карты памяти;
- папки `.thumbnails` (миниатюры) в `DCIM`, `Pictures`, `Movies`, `Music`;
- `mtklog`, `debuglogger` — отладочные журналы MediaTek, на магнитолах бывают по несколько ГБ.

**Не трогает** музыку, видео, фото, загрузки, офлайн-карты (они лежат в `files`, а не в `cache`),
настройки и сами приложения. Установщики `.apk` в `Download` только показываются в отчёте,
удалять их или нет — решаете сами.

После очистки приложения первый раз запускаются чуть дольше,
а навигаторы заново подгружают тайлы онлайн-карт.

## Подготовка

1. На компьютере установите [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools) (там есть `adb`).
2. На магнитоле: Настройки → О устройстве → 7 раз нажать на «Номер сборки»,
   затем в «Для разработчиков» включить «Отладка по USB» и «ADB по сети» / «Отладка по Wi-Fi».
   На некоторых магнитолах (FYT, TS и т. п.) этот переключатель спрятан в заводском меню.
3. Компьютер и магнитола должны быть в одной Wi-Fi-сети.
4. При первом подключении на экране магнитолы появится запрос «Разрешить отладку?» — нажмите «Разрешить».

Если на магнитоле Android 11+ и вместо «ADB по сети» есть только «Беспроводная отладка»,
сначала выполните `adb pair 192.168.2.150:<порт сопряжения>`, затем укажите порт подключения
из того же экрана: `HEADUNIT=192.168.2.150:<порт>` (в Windows — `set HEADUNIT=...`).

## Запуск

Linux / macOS:

```sh
./headunit-clean.sh              # отчёт: что занимает место, ничего не удаляет
./headunit-clean.sh clean        # очистка (спросит подтверждение)
./headunit-clean.sh apps         # списки приложений
```

Windows (из этой папки):

```bat
headunit-clean.bat
headunit-clean.bat clean
headunit-clean.bat apps
```

## Лишние приложения

Ничего не отключается автоматически: на магнитолах среди системных приложений есть
CAN-шина, радио, камера заднего хода, и их отключение ломает машину.
Посмотрите `apps`, затем отключайте по одному:

```sh
./headunit-clean.sh disable com.example.junk   # отключить (приложение остаётся, данные целы)
./headunit-clean.sh enable  com.example.junk   # вернуть
```

`disable` полностью обратим. Сторонние приложения проще удалить обычным способом через настройки.
